# Electricity Calculator


## Description
This program calculates the total electricity consumption using the current reading minus the previous reading, alongside the total bill.


## Version 1 – Original code without input validation
- Input: Accepts the customer name alongside the current and previous electric meter reading.
- Process: Calculates and displays the total electricity consumption and bill.
- Output: Total energy consumption and total bill.
- Does not include input validation.

##Version 2 - New code with input validation
- Input: Accepts the customer name with validation, name must not be empty, accepts previous and current electric meter reading with validation, number must not be 0 and number must be at least previous reading.
- Process: Calculates and displays the total electricity consumption and bill.
- Output: Total energy consumption and total bill.
- Includes input validation
